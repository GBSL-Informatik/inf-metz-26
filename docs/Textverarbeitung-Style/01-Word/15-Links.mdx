# NEU: Links

Links können sehr nützlich sein, um auf andere Webseiten oder bestimmte Stellen in Ihrem Dokument zu verweisen.

In Word können Sie Links ganz einfach erstellen, indem Sie zuerst den Text markieren, dem Sie einen Link hinzufügen möchten.
Dann können Sie entweder mit der rechten Maustaste auf den markierten Text klicken und die Option __Hyperlink...__ auswählen, 
oder Sie können die Tastenkombination __Strg + K__ (macOS: __Cmd + K__) verwenden. Es öffnet sich ein Dialogfeld, 
in dem Sie die URL der Webseite oder den Pfad zum Dokument eingeben können.

## Link zu einer anderen Stelle im Dokument

## Link zu einer E-Mail-Adresse
Sie können auch einen Link zu einer E-Mail-Adresse erstellen, damit die Leser direkt eine E-Mail an diese Adresse senden können, 
wenn sie auf den Link klicken. Dies kann zum Beispiel bei Lebensläufen nützlich sein.
