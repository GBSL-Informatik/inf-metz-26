# 🥷 Codewars

Codewars ist eine Webseite, auf der Sie Programmieraufgaben (Katas) in verschiedenen Schwierigkeitsgraden lösen können. Die Aufgaben sind oft spielerisch gestaltet und bieten eine gute Möglichkeit, Ihre Programmierfähigkeiten zu verbessern. Je mehr Aufgaben Sie lösen, desto höher steigt Ihr Rang auf der Webseite.

Webseite: https://www.codewars.com/

Diese fortgeschrittenen Konzepte müssen Sie eventuell kennen (Funktionen, Parameter und Argumente, Listen, etc.) Diese finden Sie im Abschnitt «Advanced Python».
