# Keyboard Shortcuts

Viele Aktionen am Computer können sowohl mit der Maus als auch direkt über die Tastatur ausgeführt werden. Solche **Tastenkombinationen** werden auch **Keyboard Shortcuts** oder kurz **Shortcuts** genannt.

Statt beispielsweise mit der Maus auf **Bearbeiten → Kopieren** zu klicken, können Sie einfach [[Ctrl]] + [[C]] (Windows) bzw. [[Cmd]] + [[C]] (Mac) drücken.

Bei einer einzelnen Aktion spart das kaum Zeit. Da Sie Aktionen wie Kopieren, Einfügen, Suchen oder das Wechseln zwischen Programmen aber sehr häufig ausführen, können Shortcuts die Arbeit am Computer deutlich effizienter machen.

:::insight[Shortcuts lernen]
Shortcuts lernt man am besten nicht durch Auswendiglernen, sondern durch **Benutzen**.

Versuchen Sie deshalb, häufige Aktionen bewusst mit der Tastatur statt mit der Maus auszuführen.
:::

## Wichtige Tasten und ihre Namen

## Die wichtigsten Shortcuts

Die folgenden Tastenkombinationen funktionieren in sehr vielen Programmen. Diese sollten Sie kennen und regelmässig verwenden.

<OsTabs>
  <TabItem value="win" label="Windows">

  [[Ctrl]] + [[X]]
  : **Ausschneiden** – das ausgewählte Objekt entfernen und in die Zwischenablage kopieren.

  [[Ctrl]] + [[C]]
  : **Kopieren** – das ausgewählte Objekt in die Zwischenablage kopieren. Dies funktioniert mti Text aber auch mit Dateien im Explorer.

  [[Ctrl]] + [[V]]
  : **Einfügen** – den Inhalt der Zwischenablage einfügen.

  [[Ctrl]] + [[Shift]] + [[V]]
  : **Ohne Formatierung einfügen** – in vielen Programmen wird nur der kopierte Text eingefügt, ohne dessen ursprüngliche Formatierung zu übernehmen.

  [[Ctrl]] + [[Z]]
  : **Rückgängig machen** – die vorherige Aktion widerrufen.

  [[Ctrl]] + [[Y]] oder [[Ctrl]] + [[Shift]] + [[Z]]
  : **Wiederholen** – eine rückgängig gemachte Aktion wiederherstellen. Welche Kombination funktioniert, hängt vom Programm ab.

  [[Ctrl]] + [[A]]
  : **Alles auswählen** – beispielsweise den gesamten Text oder alle Dateien eines Ordners.

  [[Ctrl]] + [[F]]
  : **Finden** – innerhalb einer Webseite oder eines Dokuments nach Text suchen.

  [[Ctrl]] + [[S]]
  : **Speichern** – das aktuelle Dokument speichern.

  [[Alt]] + [[Tab]]
  : **Programm wechseln** – zwischen geöffneten Programmen wechseln.

  [[:mdi[microsoft]]]
  : **Startmenü öffnen** – anschliessend können Sie direkt den Namen eines Programms oder einer Datei eintippen, um danach zu suchen.

  </TabItem>

  <TabItem value="mac" label="Mac">

  [[Cmd]] + [[X]]
  : **Ausschneiden** – das ausgewählte Objekt entfernen und in die Zwischenablage kopieren.

  :::info[Dateien im Finder]
  [[Cmd]] + [[X]] funktioniert nicht zum Ausschneiden von Dateien im Finder. Kopieren Sie die Datei stattdessen zunächst mit [[Cmd]] + [[C]] und verschieben Sie sie anschliessend mit [[Cmd]] + [[Option]] + [[V]].
  :::

  [[Cmd]] + [[C]]
  : **Kopieren** – das ausgewählte Objekt in die Zwischenablage kopieren. Dies funktioniert mit Text aber auch mit Dateien im Finder.

  [[Cmd]] + [[V]]
  : **Einfügen** – den Inhalt der Zwischenablage einfügen.

  [[Cmd]] + [[Shift]] + [[V]]
  : **Ohne Formatierung einfügen** – in vielen Programmen wird nur der kopierte Text eingefügt, ohne dessen ursprüngliche Formatierung zu übernehmen.

  [[Cmd]] + [[Z]]
  : **Rückgängig machen** – die vorherige Aktion widerrufen.

  [[Cmd]] + [[Shift]] + [[Z]]
  : **Wiederholen** – eine rückgängig gemachte Aktion wiederherstellen.

  [[Cmd]] + [[A]]
  : **Alles auswählen** – beispielsweise den gesamten Text oder alle Dateien eines Ordners.

  [[Cmd]] + [[F]]
  : **Finden** – innerhalb einer Webseite oder eines Dokuments nach Text suchen.

  [[Cmd]] + [[S]]
  : **Speichern** – das aktuelle Dokument speichern.

  [[Cmd]] + [[Tab]]
  : **Programm wechseln** – [[Cmd]] gedrückt halten und mit [[Tab]] zwischen geöffneten Programmen wechseln.

  [[Cmd]] + [[Leertaste]]
  : **Spotlight öffnen** – nach Programmen, Dateien und anderen Inhalten auf dem Computer suchen.

  </TabItem>
</OsTabs>

:::info[Es gibt viel mehr Shortcuts]
Sie müssen nicht jeden Shortcut kennen. Besonders sinnvoll sind Shortcuts für Aktionen, die Sie **häufig** ausführen.

Wenn Sie eine Funktion oft mit der Maus auswählen, schauen Sie einmal im Menü des Programms nach. Häufig steht der zugehörige Shortcut direkt neben der Funktion.
:::

## Mit den Pfeiltasten arbeiten

Um effizient mit der Tastatur zu arbeiten, sind auch die **Pfeiltasten** ([[:mdi[arrow-up]]], [[:mdi[arrow-down]]], [[:mdi[arrow-left]]], [[:mdi[arrow-right]]]) wichtig.

Normalerweise bewegen sie den Cursor nur um ein Zeichen. In Kombination mit anderen Tasten können Sie damit aber sehr schnell durch einen Text navigieren oder Text auswählen.

<OsTabs>
  <TabItem value="win" label="Windows">

  [[Shift]] + [[Pfeiltasten]]
  : Text zeichenweise **auswählen**.

  [[Ctrl]] + [[Pfeiltasten]]
  : Ganze **Wörter überspringen**.

  [[Ctrl]] + [[Shift]] + [[Pfeiltasten]]
  : Ganze **Wörter auswählen**.

  [[:mdi[microsoft]]] + [[Pfeiltasten]]
  : **Fenster anordnen** – beispielsweise ein Fenster auf die linke oder rechte Bildschirmhälfte verschieben.

  </TabItem>

  <TabItem value="mac" label="Mac">

  [[Shift]] + [[Pfeiltasten]]
  : Text zeichenweise **auswählen**.

  [[Option]] + [[Pfeiltasten]]
  : Ganze **Wörter überspringen**.

  [[Option]] + [[Shift]] + [[Pfeiltasten]]
  : Ganze **Wörter auswählen**.

  [[Cmd]] + [[Pfeil links]]
  : Zum **Anfang einer Zeile** springen.

  [[Cmd]] + [[Pfeil rechts]]
  : Zum **Ende einer Zeile** springen.

  </TabItem>
</OsTabs>

## Shortcuts trainieren

Shortcuts werden erst dann wirklich nützlich, wenn Sie nicht mehr darüber nachdenken müssen, welche Tasten Sie drücken müssen. Das lässt sich trainieren.

### Shortcut Game

:::aufgabe[Shortcut Game]

### Weitere Shortcuts entdecken

Auf **[ComboShelf](https://comboshelf.com/)** finden Sie eine grosse Sammlung von Shortcuts für verschiedene Programme und Betriebssysteme.

Dort können Sie beispielsweise Shortcuts für Browser, Office-Programme, Entwicklungsumgebungen und andere Anwendungen entdecken.

:::aufgabe[⭐️ Mein neuer Shortcut]
<TaskState id="944ef078-c5c2-4452-ae3d-8a995e09f7ad" />

Stöbern Sie auf [ComboShelf](https://comboshelf.com/) und suchen Sie einen Shortcut, den Sie bisher **noch nicht kannten**, der Ihnen aber nützlich erscheint.

Probieren Sie den Shortcut auf Ihrem Computer aus.

<QuillV2 id="cf35207e-d3a5-451c-b284-35d77d096ea6" />
:::

:::insight[Die wichtigsten Shortcuts]
Sie müssen keine lange Liste von Tastenkombinationen auswendig lernen.

Beginnen Sie mit einigen wenigen Shortcuts für Aktionen, die Sie häufig benötigen. Üben Sie diese Shortcuts gezielt für 1-2 Wochen bis sie Ihnen automatisch von der Hand gehen. Dann suchen Sie sich 1-2 neue Shortcuts heraus und üben diese wieder bewusst für einige Wochen. Wenn diese ebenfalls sitzen, können Sie nach und nach weitere hinzufügen bis Sie sich ein solides Repertoire aufgebaut haben.

:::
