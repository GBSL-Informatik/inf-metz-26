# Präsentation
Als Teil Ihrer Deliverables präsentieren Sie am Ende der Projektphase vor der Klasse ihr Spiel, den geschriebenen Code und reflektieren Gelerntes.

:::tip[Probelauf]
Machen Sie am besten rechtzeitig einen (oder mehrere) Probeläufe der Präsentation, um sicherzustellen, dass alles flüssig ist.
:::

## Anforderungen
- Sie erstellen eine Präsentation von **8 bis 10 Minuten** Länge.
- Die Präsentation findet am Ende der Projektphase vor der Klasse statt.
- In der Präsentation muss mindestens ein Gruppenmitglied frei sprechen und das Spiel erklären. Es ist aber auch möglich, dass mehrere Gruppenmitglieder zu Wort kommen, z.B. indem sie sich die Erklärungen aufteilen.
- Ihre Präsentation muss die folgenden Inhalte abdecken:
  - Kurze Vorstellung der Gruppe (Namen der Mitglieder)
  - Kurze Vorstellung der Story / Handlung des Spiels, gezeigt am Flowchart (max. 3 Minuten)
  - Erklärung Ihres Codes: Wo beginnt das Programm? Wie ist der Verlauf durch den Code während des Spiels? Wie wurden Probleme wie falsche oder unsaubere Benutzereingaben gelöst? Haben Sie besondere Mechanismen und Lösungen eingebaut? Wenn ja, wie funktionieren diese?
  - Was haben Sie im Rahmen dieses Projekts über das Programmieren gelernt?
